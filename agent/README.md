# Агент точки ТоргОС (камеры)

Работает на мини-ПК/Raspberry Pi в магазине рядом с видеорегистратором.
Сам открывает исходящее WSS-соединение к серверу ТоргОС — порты на
регистраторе/роутере магазина открывать не нужно и не следует.

## Установка

1. В `/admin/cameras/settings` → «Добавить агента» — получите токен и
   готовую команду.
2. На мини-ПК (Ubuntu/Debian/Raspberry Pi OS), с правами root:
   ```
   curl -fsSL https://<ваш-домен>/agent-dist/install.sh | sudo bash -s -- <TOKEN> <SERVER_WSS_URL>
   ```
   Через несколько секунд агент появится «онлайн» в настройках камер.

## Что ставится

- `/opt/torgos-agent/go2rtc` — бинарник go2rtc (RTSP → WebRTC/HLS), слушает
  только `127.0.0.1:1984`, наружу не торчит.
- `/opt/torgos-agent/agent.mjs` — сам агент: WS-туннель к серверу +
  синхронизация списка потоков в go2rtc.
- Два systemd-юнита: `torgos-go2rtc`, `torgos-agent` (агент зависит от
  go2rtc и не стартует без него).

## Диагностика

```
systemctl status torgos-agent torgos-go2rtc
journalctl -u torgos-agent -f
journalctl -u torgos-go2rtc -f
```

Если агент не выходит в «онлайн»: проверьте исходящий доступ в интернет
(нужен обычный исходящий HTTPS/WSS на 443, никаких особых портов),
правильность токена в `/opt/torgos-agent/config.json`.

## Безопасность

Агент — намеренно «глупый» релей: не хранит паролей от регистратора (их
шифрует и хранит только сервер), выполняет только запросы к адресам из
allowlist, который сервер прислал при регистрации (свой go2rtc + HTTP-порты
именно тех регистраторов, что закреплены за этим агентом). Токен агента —
как пароль к камерам магазина, храните `config.json` (`chmod 600`, уже
выставлено установщиком) в секрете.

## Обновление

Пересоздать конфиг/файлы: `sudo bash install.sh <TOKEN> <SERVER_WSS_URL>` --
безопасно запускать повторно, использует уже установленные Node/go2rtc,
если версии есть.
